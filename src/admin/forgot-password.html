Релизы 1С ADMIN
Восстановление доступа к панели управления
1 Подключитесь к серверу по SSH

Войдите на сервер, где развёрнуто приложение «Релизы 1С»:

ssh user@your-server
2 Измените настройки администратора

Перейдите в папку проекта, откройте .env и задайте новые значения ADMIN_LOGIN и ADMIN_PASSWORD:

cd ~/release1c nano .env
3 Примените новые значения

Сохраните файл и пересоздайте web-контейнер. Данные PostgreSQL и ИТС-аккаунты при этом не изменяются.

docker compose up -d --force-recreate web
ℹ После выполнения команды прежние административные сессии перестанут действовать, а сайт будет доступен через несколько секунд.
⚠ Если доступа к серверу нет — обратитесь к администратору сервера или проверьте настройки SSH-ключей.
