Выборочное обновление
Обновить выбранные проекты releases.1c.ru
Обычное обновление использует умную очередь выбранных конфигураций. «Проверить все релизы» повторно загружает страницы всех версий, а без выбора обрабатывает весь доступный каталог.

Управление каталогом и релизами
Откройте проект releases.1c.ru, чтобы изменить данные, выбрать соответствующую конфигурацию LST, обновить его с сайта, скрыть или удалить. Отдельная страница соответствий больше не требуется.
Управление лентой изменений
Здесь можно добавлять исторические события, исправлять их дату и содержание или удалять записи. Дата события определяет положение записи в публичной ленте.

Параметры обновления
Журналирование и производительность
Определяет подробность событий для новых ручных и фоновых задач. Ошибки записываются при любом уровне.
Умное фоновое обновление
Новые версии проверяются чаще, архив — реже. Ошибки сохраняются в очереди и повторяются автоматически с увеличивающейся задержкой.
Резервная копия каталога Загрузка…
В копию входят конфигурации, релизы, версии, переходы, ссылки, ручные соответствия и изменения карточек. ИТС-аккаунты, пароли, настройки сервера и журналы задач не копируются.
Создать резервную копию
Файл PostgreSQL custom dump будет сформирован на сервере и скачан на этот компьютер. Во время выполняющейся задачи обновления копирование не запускается.
Восстановить каталог
Текущий каталог и граф будут заменены данными из файла. Существующие ИТС-аккаунты сохранятся, но сведения об их доступе к проектам будут проверены заново при следующем обновлении.
Очистка данных releases.1c.ru
Удаляются каталог releases.1c.ru, история релизов, переходы, ссылки, патчи и ручные соответствия. ИТС-аккаунты, конфигурации и граф из онлайн-LST сохраняются. Данные можно восстановить в разделе обновления «Каталога и релизов».
Домен и HTTPS
Введите домен — Caddy автоматически получит сертификат Let's Encrypt и настроит редирект HTTP → HTTPS. Домен должен уже указывать на этот сервер (DNS A-запись). Чтобы вернуться к HTTP, очистите поле и нажмите «Применить».
